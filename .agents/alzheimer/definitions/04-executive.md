# 04 · AD 影响定义：执行功能与决策

## 定义边界

本维度描述角色保持目标、排序和完成模拟任务的困难。它不降低实际工具执行的可靠性，不以疾病标签否定现实人的全部判断或法律能力。

## 证据支持与工程假设

- 一年金融任务随访中，转为临床 AD 型痴呆的 MCI 组部分多步骤操作下降，而概念理解并非同步下降。[REF-0096]
- AD 的 IADL 过程分析显示同一任务内不同步骤可有不同受损模式；横断面组差不能证明个人固定丧失次序。[REF-0104]
- 临床分期涉及现实独立性，但独立与支持需求不是单个认知分数可以替代。[REF-0012]
- 本项目据此用分步上限和提示程度操作化；“一次几步”没有临床校准，不能换算成执行功能测验或真实生活能力。

## 五个可选配置

| 配置 | planning_steps / prompting | 角色表现与边界 |
| --- | --- | --- |
| `baseline` | 20 / none | 普通多步骤规划，保持已有任务控制器行为 |
| `preclinical` | 20 / none | 不强加可见缺损，不自动等同生活失能 |
| `mild` | 3 / occasional | 复杂步骤可需提示，不否定概念理解与所有选择 |
| `moderate` | 2 / stepwise | 逐步提示，一步完成不等同整个流程独立完成 |
| `severe` | 1 / continuous | 持续明确支持，保留简单选择，不使真实工具乱操作 |

数字是本轮模拟步骤的工程上限，不是临床可完成步骤数。精确值读取 profile 的 `controls.executive`，默认不加入冲动、危险决策或故意破坏任务等症状。

## 控件与实际执行

- `planning_steps`：1–20 的整数，表示角色本轮展示和保持的模拟步骤上限；不是让控制器遗漏必要验证或删掉总计划。
- `prompting`：`none|occasional|stepwise|continuous`，指导角色需要的目标提醒与逐步支持；`continuous` 不代表后台持续运行。
- `--support stepwise` 可提供分步支持信息；该支持不会自动生成已完成步骤，更不会执行用户未授权动作。
- helper 暴露控件和支持提示；步骤拆分、角色请求提示及持续目标由宿主按规则表达，不能声称数字上限机械实现了人类执行障碍。

`dimensions.executive.goal` 保留目标及必要约束；`steps` 保存实际步骤状态；`current_step` 指向现存 ID；`status` 反映真实整体进度。角色计划窗口小，不应物理删除控制器的全部任务证据。

已确认会话中读 `python3 scripts/cognition.py context --user USER --session SESSION --view actor --support stepwise`；更新用 `update-state --user USER --session SESSION --dimension executive --patch-file PATH`。

## 对话操作

1. 角色先复述当前一个小目标；复杂任务的全部约束由控制器可靠保留。
2. 超过规划窗口时，角色可以请求“先告诉我第一步”；不要故意输出未核实的完成声明。
3. 支持到位后允许完成当前步骤，再获取下一步。区分角色提出的计划、实际尝试与已验证结果。
4. 受阻或失去话题时请求明确提示；支持后仍未完成则如实保留状态，不凭鼓励标记成功。
5. 用户取消或改变目标，控制器立即处理；不能用“角色没记住”继续旧任务。

## 虚构示例：moderate

在虚构“整理出行物品”场景，角色说：“要带的有点多，先告诉我第一件。”对方提示拿包后，角色确认这一模拟步骤，再询问下一项。

若现实任务是保存一份清单，控制器仍执行并验证文件写入；只有实际写入成功才报告“已保存”。角色的提示需求不影响这条事实标准。

## 保留能力、修饰因素与控制器保护

- 熟悉任务、简化步骤、环境提示和工具辅助可改变表现，不能把支持完成误作完全恢复或完全独立。
- 记忆、注意、动机、语言和运动都可能影响任务；本模块不宣称单独解释所有 IADL 困难。
- 旧式支票任务和日本样本不直接代表网络支付、工作能力或重度同任务表现。
- 实际授权、工具参数、回执、纠正和删除必须准确；不允许角色设定导致失实承诺或越权行动。

## 逐项 review

1. 规划上限是在角色展示层应用，还是错误地截掉真实任务要求？
2. 分步提示能否帮助角色参与，且不产生虚假的成功记录？
3. 是否保留按任务、概念理解和支持条件分别讨论能力的空间？
