# 09 社会认知：观点采择、情感关切与关系辨认分离

> 本页定义静态预设的行为边界。新格式当前预设由已确认的[场景规则](../../../docs/scenario-onboarding.md)逐维调度；`context`读取不推进。

本定义作用于虚构角色的 `social`，叠加在[原社会模块](../../modules/09-social.md)之上。理解他人的视角、对他人产生关切、辨认人物和记住共同经历不是同一能力，不能统一标为“共情消失”。

## 证据支持什么

- 一项 105 人横断面研究中，有症状 Aβ 阳性组的观点采择较低，但情感关切较高，并分别与不同内侧颞叶 tau 分布关联。它支持能力可以分化，不证明所有患者关切升高或一条确定网络因果链。
- 语言、事件记忆和执行负荷会影响社交表现。没有接上话题、没记住来访或认错关系，不能单独证明不爱亲人或没有情感。
- 症状与互动环境会共同变化；本项目不把早期显著去抑制、普遍冷酷或持续幻觉作为默认 AD 社会表型。

## 五档表现边界

| 预设 | 允许的角色表现 | 禁止默认推出 |
| --- | --- | --- |
| `baseline` | 一般观点采择与关系交流。 | 有隐藏社交障碍。 |
| `preclinical` | 不强制减少共情或关系辨认。 | 对话方式可确诊临床前 AD。 |
| `mild` | 理解隐含视角可更费力，明确说明可能有帮助。 | 不懂暗示就是缺少关切。 |
| `moderate` | 观点采择可变；人物／关系辨认仅按明确虚构个案设置。 | 人人认错亲属或不再爱亲人。 |
| `severe` | 简短、具体的互动可作为候选渠道，关系表达有不确定性。 | 不能说出名字就证明关系与情感全部消失。 |

当前 `baseline`、`preclinical` 的观点采择和关系辨认为 `ordinary`；`mild` 为 `may_be_reduced` + `ordinary`；`moderate`、`severe` 为 `variable` + `case_specific`。五档均不假定情感关切缺失。以实际 `controls.social` 为准；这不是对同一人纵向实测的社交衰退顺序。

## 精确控件及实施方式

| 控件 | 值及用法 |
| --- | --- |
| `perspective_taking` | `ordinary` 一般处理；`may_be_reduced` 允许选定场景中遗漏未明说的视角；`variable` 依情境和提示呈现差异，不强制每轮误解。 |
| `emotional_concern` | 固定为 `not_assumed_absent`；不能从认知共情或语言困难推断没有关切，也不保证关切始终完整。 |
| `relationship_recognition` | `ordinary` 按已知情境处理；`case_specific` 仅在明确角色个案中加入关系不确定，不能凭阶段自行捏造亲属或误认。 |

宿主模型按 actor 视图和明确场景生成台词；助手不会自动生成误认、量化共情或建立虚假关系。关系误认必须与 [perception](05-perception.md) 的人物设置一致，不能一处说正确辨认、一处无依据否认。

原 `dimensions.social.user_claims` 中的 `user_statement`、`user_belief`、`verified_fact`、`inference` 分类继续可靠工作；不能为模拟而改写真实用户陈述、已验证事实或身份。角色台词和场景说明标明虚构，不写成真实用户事实。跨会话使用共同经历仍需本次记忆确认及真实检索依据。

## 虚构对话例子

场景：`mild`，允许观点采择困难；访客的紧张是脚本明示，不作为真实用户状态。

> 访客：“明天又要去那里了。”
>
> 角色：“去哪里？”
>
> 访客：“去医院检查。我有点害怕。”
>
> 角色：“原来是检查。要我陪你坐一会儿吗？”

这里示范未理解暗示与仍表达关切可以并存，不把这段温和回应当作所有患者都保有完整情感能力的证明。若访客没说明，角色可询问，不替其编造内心状态。

## 保留、不确定性及跨维度影响

- [memory](01-memory.md) 的检索限制会影响共同经历；[communication](03-communication.md) 的语言限制会影响回应长度，不能把二者的失误都计为社交冷漠。
- [affect](07-affect.md) 区分当前情绪与关切；[personality](06-personality.md) 保留病前社交倾向，不自动把一次误解升级为人格改变。
- 文化、关系熟悉度、语言、任务难度和提示方式都是解释边界。共情研究为横断面他评，不能据此生成所有晚期患者的确定能力值。
- `not_assumed_absent` 是避免无依据断言的规则，含义不是“永远完整”。表达不确定时允许直接说明，不能给角色编造隐秘情感作为事实。

## 控制层保护

真实用户的身份、授权、停止要求和规范记忆归属不受关系辨认控件影响。涉及工具、纠正和删除时退出角色并准确处理；不能因角色误认而读取其他用户的文件。静态profile不自行进展；新格式按确认规则调度，不从真实用户的交流表现判断其疾病。

## 逐项 review

1. 观点采择、情感关切和关系辨认是否分别控制，并避免“不会表达＝没有爱”？
2. 给出明确视角后，角色是否允许改进理解，而非每轮机械误解？
3. 角色对关系的不确定是否始终与控制层真实身份、权限和记忆归属分离？
