# 十二个维度 · 静态教育页面

中文入门页面，解释十二个功能维度的正常机制、日常例子、AD 角色模拟边界与可选设定问题。每个维度链接固定研究提交中的证据卡，并注明阅读范围和局限。

页面只有说明和阅读交互，不收集角色答案、不启动模拟，也没有接入问卷后端。跳过设定后生成虚构背景、保留来源与允许编辑，是项目启动流程的职责；页面只解释该行为。

## 在线入口

配置的私有站点为 <https://cognitive-twelve-dimensions.robustdegu4.chatgpt.site>，需要相应访问权限；内容由维护者部署更新。仓库中的五个源文件仍可独立预览。

## 预览

从仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web/dimensions
```

然后打开 <http://127.0.0.1:8765>。页面使用同源 `fetch` 读取 `dimensions.json`，直接以 `file://` 打开时可能被浏览器阻止；需使用 HTTP 静态服务。结束预览时按 `Ctrl+C`。

部署时只需将此目录五个文件作为同一静态目录提供，不需要构建、模型服务或数据库。不要把 `state/`、问卷草稿、个人对话或凭据复制到网页目录。部署由项目维护者另行处理。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 中文内容入口、阅读提示与无脚本替代链接 |
| `styles.css` | 纸色、墨色和青绿的响应式排版及交互样式 |
| `app.js` | 分类、搜索、原生详情弹窗与本次阅读进度 |
| `dimensions.json` | 十二个维度说明、可选问题及 23 条证据卡元数据 |
| `README.md` | 预览、内容边界与验收说明 |

无外部脚本、字体、图片、CDN、追踪、Cookie 或浏览器持久化存储。搜索词、当前筛选和已读集合仅在页面内存中使用，刷新后重置；没有答案输入或数据提交接口。外部研究与仓库链接仅在用户主动点击时导航。

## 内容与交互验收

- 桌面、平板和窄屏下均有十二张卡片，中文标题不溢出；320 px 宽度可正常阅读。
- 三个分类分别显示 5、4、3 个维度；全文搜索可查标题、功能说明、例子及设定问题，无结果时可一键清除。
- `Tab` 可到达筛选、搜索和卡片；`Enter` 打开详情，`Escape` 关闭，关闭后焦点回到原卡片；弹窗内的上一项、下一项与已读按钮可键盘操作。
- 已读进度只有用户主动标记后才增加，重复点击可撤销；刷新恢复 0/12。
- 每项详情均含正常机制、日常例子、模拟区别、可跳过的设定问题及证据；链接明确在新窗口打开。
- 搜索与证据文本使用 DOM `textContent`，不会把输入解释成 HTML；JSON 读取失败时显示可恢复的错误提示。
- 开启减少动态效果时不平滑滚动或进行过渡；文字与背景应维持足够对比。
- 浏览器网络面板仅应出现本目录静态资源请求；页面不会向项目后端提交搜索、阅读进度或个人资料。

“正常机制”是功能性教学说明，并非把 AD 文献当作完整正常认知教材。疾病预设为未经临床校准的工程假设，不能用于真实人的诊断、病程预测、法律或现实能力裁决；模拟语言和状态值也不能证明 AI 具有主观体验。
