# Alzheimer-Simulation 项目首页

项目的中文静态介绍页，保留原 `web/dimensions` 路径和站点身份。首页说明基于 AD 研究的 AI 角色实验、场景问卷、三种演变模式、五档工程预设、文件记忆、角色与控制层边界，以及在 agent 宿主中开始使用的方法；十二个维度阅读器位于 `#explore`。

受影响的是模拟 AI 角色，真实用户是对话者。页面本身不运行模拟、不调用模型、不收集背景答案，也没有聊天后端。示例角色和对话为明确标注的固定虚构内容。

## 在线入口

同一私有站点：<https://cognitive-twelve-dimensions.robustdegu4.chatgpt.site>，需要相应访问权限。问卷可直接链接 <https://cognitive-twelve-dimensions.robustdegu4.chatgpt.site/#explore>。部署由项目维护者更新；网站目录和身份没有迁移。

开始使用应打开 [feature/alzheimerAffected](https://github.com/HeathHuang-7243/Alzheimer-Simulation/tree/feature/alzheimerAffected)，该分支包含场景问卷与新格式运行工具；`main` 保存认知母版。研究综述和文献引用固定在研究仓库的 `b3138712baf799f0145e5fb3e0c635d4d5dd4d26` 提交。

## 本地预览

从仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory web/dimensions
```

打开 <http://127.0.0.1:8765>。维度阅读器使用同源 `fetch` 读取 `dimensions.json`，需通过 HTTP 静态服务打开；直接使用 `file://` 可能被浏览器阻止。结束时按 `Ctrl+C`。

仅部署本目录网页资源，无需网页构建、数据库或模型服务。不要复制 `state/`、个人背景、草稿、对话、凭据或运行状态到站点。正式模拟仍需要模型宿主、仓库读写能力及用户明确确认。

## 文件与职责

| 文件 | 作用 |
| --- | --- |
| `index.html` | 完整项目叙事、场景示例、模式说明、启动方法与原维度阅读器 |
| `styles.css` | 纸色、青绿、深墨色的响应式排版及可访问交互样式 |
| `project.js` | 模式 tabs、虚构场景示例切换及复制启动指令 |
| `app.js` | 原维度分类、搜索、详情弹窗和本次阅读进度 |
| `dimensions.json` | 原十二个维度教学内容、可选问题及证据卡元数据 |
| `README.md` | 预览、内容边界与验收说明 |

网页不引入外部脚本、字体、图片、CDN、追踪或浏览器持久化存储，也不设置业务 Cookie；站点访问沿用已有的私有权限。唯一主动资源读取是本站的静态 JSON。搜索、已读状态、示例选择和当前模式仅在页面内存中使用，刷新后重置；模式切换只展示规则，不执行概率抽取、计时或模拟进展。外部来源链接仅在点击时导航。

## 交互验收

- 项目入口、研究依据、场景、三模式、角色与控制层、十二维、如何开始及继续/新建均可阅读；所有页内锚点有实际目标。
- 模式 tabs 可点击，也可用左右方向键、`Home`、`End` 切换；各自独立说明触发、冷却、时间、上限与工程边界。
- 场景示例切换实际更新纯虚构角色卡，并区分认识原型、过去认识对话者、当前认得对话者；不收集个人资料。
- 展开启动指令后可复制。剪贴板不被允许时选中文字并明确提示手动复制，不谎报成功。
- 十二张卡片保留 5/4/3 分类、全文搜索、无结果清除、原生详情弹窗、已读标记与撤销。键盘可打开、退出并回到原卡片；刷新进度清零。
- 检查 320、390、768、1440 px，以及三个模式的实际显示内容；不靠裁剪隐藏交互消除溢出。
- 减少动态效果设置下不平滑滚动或进行过渡；按钮和输入均有可见焦点。
- 网络请求只应是本站静态资源；没有个人资料提交、虚构后台回应或实际模型调用。
