SLOW · 首次起点只在启动时抽取一次

先等待首次起点，再分散执行变化。

首次起点位于第 N 天 ±1 天，之后把维度变化分布在设定的持续天数内。默认 N=10，持续 3 天，可在设定卡中修改。

到期后，也只在新的用户对话到来时执行；每次最多补一个维度步骤，离线期间没有后台计时触发。

从一次明确的设定开始。

打开项目仓库 ↗（新窗口）

在能够读取、持久写入仓库的模型或 agent 宿主中使用。此网站提供项目说明与阅读交互，不运行聊天或调用模型。

  1. 01

    读取项目入口

    让宿主模型加载仓库说明、模块与工作流。普通目录不会自行运行。

  2. 02

    完成场景问卷

    选择新建或继续，设置关系、经历、预设与演变。叙事细节可以跳过。

  3. 03

    审阅设定卡

    检查虚构来源、初始条件、时间、参数和新建时的清理范围，再确认。

  4. 04

    开启并确认记忆

    在平台设置开启记忆，再明确告诉模型。模型无法检测开关。

  5. 05

    开始角色对话

    宿主按当前模拟 ID 读写状态，记录事件、表现与实际变化。

两项确认都需要。

叙事留白可以生成虚构替代；设定确认和平台记忆自报不能代填。平台记忆与仓库记忆分别运行，开启前者不会自动读取或同步仓库。

ONE ID, ONE SIMULATION

继续一段经历，
或确认新的开始。

每次独立模拟拥有自己的 ID。换一个聊天窗口，本身不会把它变成一段新模拟。

RESUME

继续同一 ID

保留背景、十二个维度与记忆。重新连接宿主时，再确认平台记忆自报，接续当前运行。

NEW RUN

确认开始新模拟

先构建新运行并切换，再清理同一用户上一活跃的新格式运行。旧背景、维度和记忆不继承，也不自动归档；仅准备草稿不会清理。

经历发生时间、实际记录时间、故事时钟分别保存，未知日期保持未知。所有运行状态都在仓库目录内，无数据库；新建清理不擦除平台记忆、外部副本、其他用户或项目代码。
