BEFORE YOU SET THE SCENE

你可以了解，
也可以先留白。

这些维度用于丰富虚构角色，并不要求你交出真实个人的健康、家庭或生活资料。

01

设定问题都可以跳过

如果不提供细节，启动流程会用带有来源标记的虚构内容补齐背景。生成内容可以检查、修改，不会被当作真实个人事实。

02

一个维度的变化，不代表全部改变

找词、记忆、动机和情感关切可能分化。疾病研究提供边界，工程参数与角色台词仍需验证；预设不能代表所有患者。

03

这页只负责解释

本页不收集角色资料、不启动模拟，也不保存搜索与阅读进度。回到对话后再选择设定；正式启动仍需确认角色卡并按项目要求开启平台记忆。

※

阅读证据，也阅读它的边界。

“正常机制”是便于理解的功能说明；AD 相关文献并非完整的正常认知教材。每个维度附有证据卡，标明实际阅读范围与人群限制。模拟预设尚未经临床校准，不能用于诊断、病程预测或现实能力裁决；AI 的角色表达也不证明其具有主观体验。
